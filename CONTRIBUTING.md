# Contributing Guidelines

Welcome to the AI-Assisted Project Management Dashboard repository! Please follow these guidelines to ensure secure collaboration and governance alignment.

## Branching Strategy
We follow **GitHub Flow**:
- `main`: Production-ready code. Direct pushes are disabled; changes must come via Pull Requests.
- `feature/*`: For new features or tasks (e.g., `feature/copilot-integration`).
- `bugfix/*`: For resolving bugs or security alerts.

## Commit Message Convention
Please use clear, descriptive commit messages:
- `feat: [description]` for new features
- `fix: [description]` for bug fixes
- `docs: [description]` for documentation updates
- `sec: [description]` for security enhancements

## Pull Request Process
1. Create a descriptive feature branch from `main`.
2. Open a Pull Request and ensure the PR template is filled out completely, including the Responsible AI check.
3. Request a review from a team member. At least **one approving review** is required before merging.
4. Ensure all status checks (like CodeQL and Dependabot) pass successfully.
